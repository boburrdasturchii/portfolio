# 🚀 Bobur dasturchi — Shaxsiy Portfolio 2.0 (Kengaytirilgan Talqin)

Ushbu loyiha **Bobur Mirboboyev** (13 yosh, 10-maktab va Mars IT School o'quvchisi) uchun maxsus yaratilgan ultra-zamonaviy, interaktiv shaxsiy portfolio veb-platformasidir.

## 🌟 Yangi qo'shilgan ilg'or funksiyalar va imkoniyatlar:

1. **⚡ Interaktiv CLI Dasturchi Konsoli (Terminal):**
   - Foydalanuvchilar terminal orqali `help`, `about`, `age`, `skills`, `projects`, `roadmap`, `mars`, `contact`, `matrix`, `confetti`, `sound`, `theme`, `calc`, `quote`, `clear` buyruqlarini kiritishi va boshqarishi mumkin.
   - Avtomatik taklif (Tab completion) va kiritilgan buyruqlar tarixi (Up / Down tugmalari).

2. **🎨 4 Xil Neon Rang Mavzulari (Theme Accent Switcher):**
   - **Cyber Violet:** Zamonaviy kiber-binafsha va pushti gradientlar (standart).
   - **Mars Flame:** Mars IT School va Mars Space ramziy olovrangi.
   - **Emerald Matrix:** Xakerlik va kiber uslubdagi zumrad yashil.
   - **Google Blue:** Google ranglari uyg'unligi (katta maqsad ramzi).
   - Tanlangan rang `localStorage` da avtomatik saqlanib qoladi.

3. **🎵 Web Audio Mexanik Klaviatura Ovoz Effekti:**
   - Hech qanday og'ir audio fayllarsiz, brauzerning sof Web Audio API orqali sintez qilingan realistik chertish va muvaffaqiyat tovushlari.
   - Bir tugma bilan ovozni yoqish/o'chirish imkoniyati.

4. **🟩 Kiber Matrix Yomg'iri (Digital Rain Canvas):**
   - Bitta bosish bilan ekranda dasturchilar sevgan afsonaviy Matrix yashil kodlar oqimi yoqiladi.

5. **🎉 Sof JavaScript Konfetti Animatsiyasi:**

6. **🧠 Obsidian "Ikkinchi Miya" Interaktiv Bilimlar Grafigi:**
