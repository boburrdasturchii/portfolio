# 🚀 Bobur dasturchi — Shaxsiy Portfolio Veb-sayti

Ushbu portfolio **Bobur Mirboboyev** (13 yosh, 10-maktab o'quvchisi) uchun maxsus yaratildi. Loyihadagi barcha ma'lumotlar Obsidian bilimlar bazasidagi qaydlarga asoslangan.

## 🌟 Loyiha xususiyatlari:

- **Premium CSS Dizayn:** Ultra-zamonaviy qorong'i rejim (Dark Mode), Glassmorphism (shishasimon xiralashish effekti), neon gradientlar va silliq soyalar.
- **Interaktiv Terminal Karta:** 3D sichqoncha harakati effektiga ega dasturchi kod oynasi.
- **Google Sari Yo'l Xaritasi (Roadmap):** 4 bosqichli professional rivojlanish rejasi.
- **Moslashuvchanlik (Responsive):** Kompyuter, noutbuk, planshet va smartfonlarda chiroyli ochiladi.
- **Tezkor va yengil:** Hech qanday og'ir freymvorklarsiz, sof HTML5, CSS3 va JavaScript.

## 📂 Fayllar tuzilmasi:

- `index.html` — Asosiy semantik sahifa
- `style.css` — Premium darajadagi zamonaviy uslublar
- `script.js` — Silliq navigatsiya va interaktiv effektlar

## 🖥️ Qanday ochish mumkin?

`index.html` faylini ikki marta bosib, istalgan brauzerda (Google Chrome, Microsoft Edge va h.k.) ochishingiz mumkin.
